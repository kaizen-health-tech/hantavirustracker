# Data Pipeline

Production records should be published from normalized JSON generated by ingestion jobs, not edited directly in UI code.

## Publication Rules

- Official public-health sources create canonical records.
- News articles can be attached as citations or monitoring signals.
- Non-official signals should enter a review queue before publication.
- Every map record must include source URLs, timestamps, confidence, and geographic precision.

## Recommended Refresh Cadence

- WHO Disease Outbreak News: every 60 minutes.
- CDC NNDSS: daily check; weekly publication expected.
- National, state, and local public-health authorities: every 30-60 minutes during active events.
- News citations: every 15-30 minutes, publish only after review.
